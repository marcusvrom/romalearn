# Roteiro de teste — cursos de tecnologia

## Preparação

```bash
pnpm seed
pnpm seed:demo
```

Conta principal:

```text
trilha@romalearn.local
```

Nome esperado: **Fernando Trilha**.

A conta deve exibir matrícula ativa em:

- Git e GitHub na Prática;
- Lógica de Programação e Algoritmos;
- HTML e CSS do Zero;
- JavaScript — Fundamentos;
- Python para Iniciantes;
- Java — Fundamentos e Orientação a Objetos.

## Validação das leituras

Para ao menos uma aula de cada curso, confira:

- contexto e problema do dia a dia;
- explicação do que, como e por que;
- exemplo específico da tecnologia;
- laboratório guiado;
- erros comuns;
- reflexão;
- checklist;
- conexão com a atividade e o projeto.

## Validação das atividades

Confira se cada atividade possui:

- situação-problema;
- objetivo de aprendizagem;
- entregáveis;
- cenários mínimos;
- roteiro de desenvolvimento;
- reflexão obrigatória;
- checklist antes do envio.

A atividade deve exercitar o conteúdo anterior, e não introduzir um conceito essencial sem explicação prévia.

## Casos ponta a ponta

1. Git: criar repositório, commits, branch, PR, README e release.
2. Lógica: criar organizador de tarefas com casos comuns e inválidos.
3. HTML/CSS: publicar landing page responsiva e acessível.
4. JavaScript: consumir API com estados de carregamento, vazio e erro.
5. Python: consolidar CSV preservando arquivos originais.
6. Java: implementar regras de empréstimo e testes básicos.

## Áudio

- reproduzir leitura em 1,75x;
- verificar se blocos de código são ignorados ou tratados adequadamente;
- conferir pronúncia de HTML, CSS, API, GitHub, JavaScript, Python, Java, JDK e JVM;
- testar pausa e retomada.

## Critérios de aceite

- Fernando possui acesso a todos os cursos;
- nenhuma aula aparece vazia;
- exemplos renderizam como código;
- atividades não duplicam texto de forma confusa;
- questionários funcionam;
- projetos exigem aprovação por rubrica;
- segunda execução dos seeds não duplica acessos, matrículas, aulas ou ofertas.
